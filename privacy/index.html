Privacy Policy

Last updated: 2026-10-13

This is the privacy policy page for UmaAutomoderator Discord bot ("we," "our," or "us"). We are committed to protecting your personal information and your right to privacy. If you have any questions or concerns about our policy or our practices regarding your personal information, please contact @orangeblue2336 on Discord.

1. Data we process

  • Message content: Message text is read in real time to detect spam. It is NOT stored. For same-message spam, only a temporary hash is kept in memory for a short time (about 15 seconds). When action is taken, up to 300 characters of the offending message may be shown in the server's private moderation log channel.
  • Member info: When a member joins, the account creation date is checked in real time and is NOT stored.
  • Attachments: Normally only the channel where an image was posted is remembered, briefly, in memory. If one user posts images in several different channels within a short time, those images are downloaded temporarily into memory to compute a similarity hash and compare it with known scam images. If scam keywords are configured, a resized copy may also be sent to the OCR.space service to extract text. We do not keep the images.
  • Role icon images: If a server booster uses the role icon command, the attached image is downloaded temporarily to check its type and size and is then uploaded to Discord as the role icon. We do not keep it.
  • Direct messages: When the bot takes action against a member, it sends that member a DM explaining what happened. The bot does not read DMs sent to it.

2. Data we store

For moderation purposes, we store these data on MongoDB Atlas, where stored data is encrypted at rest:

  • Message log: message ID, user ID, channel ID, timestamp. It is used only to delete a spammer's recent messages and is automatically deleted after about 65 minutes. Message content is never stored.
  • Server settings: feature on/off, whitelisted role IDs, exempt channel IDs, list of known scam image hashes and scam keywords added by moderators, together with the Discord user ID of the moderator who added each entry. These entries contain no data about ordinary members and are removed when a moderator deletes them.
  • Moderation actions are recorded in the server's private log channel.

3. Third parties

Discord, Render (hosting), MongoDB Atlas (database), OCR.space (text extraction from images).
We do not sell data, share it for advertising, or use it to train machine learning or AI models.

4. Retention and deletion

Data about member activity (the message log above) is automatically deleted after about 65 minutes, and message content is never stored, so normally there is nothing to delete. If you believe we hold data about you, or want to ask about it, contact us below and we will look into it and remove it where we can.
